          Small-signal context
          
          
          
Use named nets, physical net IDs, or terminal references. These DC bias ports are treated as AC ground.

          Textbook approximations
          
          
          
          
          
          
          
These are explicit textbook simplifications. Miller's theorem can split any linear impedance between a stage input and output, but this tool applies it only when the device is marked gmro ≫ 1 and a safe DC stage gain can be derived. Exact symbolic equations remain in the details, and every selected approximation is listed as an assumption.
