      Beats

      Small-signal analysis

      Pick the input and output, then Derive.

      Signals

      Supplies and grounds are already AC ground. Add bias nets by name, net ID, or pin (M5.g).

      Options
      Transfer functions

      A current input drives the input node; a current output flows into the shorted output node, as in Zout. Input and output impedances are always derived.

      Where the loop breaks: an opamp (T = Aβ), a terminal (M2.g), the net that closes the loop, or two nets when it is not drawn closed (V_fb to V_inn). Empty: no loop gain.

      Each capacitor's time constant C R, R what it sees with the others open: their sum sets the dominant pole, and with up to six capacitors the pairs give the next.

      Model simplifications

      These change the model before it is solved: the branch is left out, so the small-signal netlist and the Model tab show what was actually solved.

      Equation approximations

      These simplify the displayed equations only. Exact equations remain in the Log tab.

      Noise

      Low-frequency densities, referred to the input and to the output. Each checked MOS device and resistor adds one generator; uncheck the ones that do not matter.

      Small-signal context

      Use REF=triode to replace a MOS device with its symbolic rds.

      The circuit changed since these equations were derived.
